# 🎭 主持与戏剧表演队 — 回忆纪念网站

## 快速启动

```bash
# 1. 安装依赖（已完成可跳过）
npm install

# 2. 启动服务器
node server.js

# 3. 浏览器打开
# http://localhost:3000
```

## 默认管理员

首次启动时会自动创建管理员账号：

| 项目 | 值 |
|------|-----|
| 姓名 | 管理员 |
| 邀请码 | admin2024 |
| 密码 | admin123 |

> ⚠️ 请第一时间登录修改密码！可在 `.env` 文件中修改 `ADMIN_INVITE_CODE` 更改邀请码。

## 管理员操作指南

### 1. 导入队员名单

1. 打开网站 → 点击底部「**主持记忆**」
2. 向下滚动找到「**🔧 管理操作**」区域
3. 点击「**📋 导入名单**」
4. 在文本框输入队员姓名，**每行一个**或**逗号分隔**，例如：
   ```
   张三
   李四
   王五
   ```
5. 点击「导入并生成邀请码」
6. 系统会为每个名字生成一个 **8 位邀请码**，记录下来发给对应队员

### 2. 查看邀请码

- 在管理操作区点击「**🔑 查看邀请码**」
- 可看到所有人的邀请码和注册状态
- 将邀请码分别发给对应队员

### 3. 上传大合照

1. 在「主持记忆」页面，点击右下角 **+** 按钮
2. 选择照片，填写标题
3. 点击上传

### 4. 添加活动记录

1. 在管理操作区点击「**+ 添加活动**」
2. 填写活动标题、日期、地点、描述

## 队员操作指南

### 注册

1. 打开网站 → 点击底部「**我的**」
2. 点击「**注册**」
3. 输入管理员给你的 **邀请码**、**姓名**（必须和名单一致）、**设置密码**
4. 完成注册，自动登录

### 上传照片

1. 进入「**我的**」页面
2. 点击「**📸 上传照片**」
3. 选择一张或多张照片
4. 照片会出现在你的个人页面，同时汇总到「**队员风采**」板块

### 编辑个人简介

1. 进入「**我的**」页面
2. 点击「**✏️ 编辑简介**」
3. 写下自我介绍，保存

### 换头像

1. 进入「**我的**」页面
2. 点击「**📷 换头像**」
3. 选择头像图片

## 点赞与评论

- 每张照片、每个队员主页、每条活动记录下方都有 **❤️ 点赞** 和 **💬 评论** 按钮
- 登录后即可给任何人点赞和评论
- 在「**主持记忆**」可以给大合照和活动记录点赞留言
- 在「**队员风采**」点击队员卡片进入详情页，可以给队员和他的照片点赞留言

## 部署上线

推荐使用免费平台：

### Railway
1. 将项目文件夹上传到 GitHub
2. 在 [railway.app](https://railway.app) 导入仓库
3. 设置启动命令：`node server.js`
4. 添加环境变量：`SESSION_SECRET`（随机字符串）

### Render
1. 上传到 GitHub
2. 在 [render.com](https://render.com) 创建 Web Service
3. Build Command 留空，Start Command：`node server.js`

部署后会获得一个公开 URL，可在浏览器、微信、QQ 中打开。
